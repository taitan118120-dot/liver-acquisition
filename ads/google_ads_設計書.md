## 5. 共通設定

### 5-1. 地域ターゲティング

> **設計変更（2026-07-20 練り直し）**：当初の「13地域ホワイトリスト」は対象人口が約1,000万人＝全国の8%しかなく、ニッチ語の検索在庫を絞り殺して月8万円を消化できない構造だった。所属は全国どこからでも可能なサービスなので、**「全国配信＋高CPC都市圏だけ除外」方式**に反転する。在庫が6〜7倍になり、Googleが安いクリックを全国の地方から拾えるようになる。

| 設定 | 内容 |
|---|---|
| 対象地域 | **日本全国** |
| 除外地域 | **東京都・神奈川県・埼玉県・千葉県・大阪府・愛知県・福岡県**（CPC高騰と大手競合が集中する都市圏を丸ごと回避。人口の約45%を切るが、残り55%＝約7,000万人が対象になり旧方式の6倍以上） |
| ターゲット指定方法 | 「**所在地**」（対象地域にいるユーザー）を選択。「関心を示した地域」は**選ばない**（旅行者等の無駄クリック防止） |
| 除外の指定方法 | 同じく「所在地」ベースで除外 |
| 入札調整 | **石川県・富山県・福井県 +15%**（地元優位で成約率が高い想定）。それ以外は±0%で開始し、月1の地域別レポートで調整 |

**段階ルール**
- 埼玉・千葉は「都市圏だがCPCは東京ほどでない」中間地帯。開始3週間で日予算の消化率が90%超なら除外のまま、**消化率70%未満なら埼玉・千葉を解除**して在庫を足す。
- 逆に特定県のCPAが全体平均の2倍超が2ヶ月続いたら、その県を個別除外。
- 「地方から活躍できる」訴求（軸②）は全国の地方在住者にそのまま刺さるため、LP・広告文の変更は不要。

### 5-3. 配信スケジュール

配信を始めたい層は**平日の夜と休日の日中〜夜**に検索が集中する。深夜〜早朝は無駄クリックが多いため停止。

| 月〜木 | 07:00-09:00 | -20% |
| 月〜木 | 12:00-14:00 | ±0% |
| 月〜木 | 19:00-24:00 | **+20%** |
| 金 | 12:00-14:00 | ±0% |
| 金 | 19:00-24:00 | +10% |
| 土・日 | 10:00-24:00 | **+20%** |
| 全曜日 | 00:00-07:00 | **配信停止** |

- タイムゾーン：日本標準時（アカウント設定で確認）
- ※「クリック数の最大化」利用中は時間帯の入札調整比率が効かない場合があるため、**まずは配信ON/OFFだけ設定**し、比率調整はコンバージョン最大化に切り替えた後から入れる。

### 5-4. 入札戦略

**切り替え条件（すべて満たしたら切り替え）**

1. そのキャンペーンで**直近30日のコンバージョンが30件以上**（Google推奨の学習下限）

**切り替え後の注意**

- 切替直後2週間は「学習期間」でCPAが一時的に悪化する。この間はキーワード削除・予算変更を**行わない**。

### 6-3. 増額判断

| 条件 | アクション |
|---|---|
| **応募1件あたり5,000円以下**（CPA≦5,000円）が2週連続 | 該当キャンペーンの予算を**+20%**。翌週に再評価 |
| CPA 5,000円以下 かつ インプレッションシェア（予算による損失）20%超 | 予算を**+50%**まで引き上げ可 |
| CPA 3,000円以下が1ヶ月継続 | 月予算100,000円 → 150,000円への総額引き上げを検討 |
| 増額後にCPAが7,000円超に悪化 | 元の予算に戻す |

**増額のやり方**：一度に倍増させない。**+20%ずつ、1週間空けて**上げる。急な増額は学習をリセットしCPAが跳ねる。

**予算配分の原則**：Aが好調でもCの30,000円は撤退判定（30日）まで動かさない。テストは最後まで走らせて結論を出す。予備枠5,000円は週1チェックでCPA最良のキャンペーンに上乗せする。
