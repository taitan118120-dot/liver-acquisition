# 小松の物件ウォッチャー

小松市空き家バンクを巡回して、**ガイドv2 §0の式に収まる築古戸建てが出たらLINEに通知**する。

```
総投資上限（物件+諸費用+修繕） = 年間手残り × 5   ← 実質利回り20%の定義
```

## なぜこれが要るのか

2026年7月時点、小松市空き家バンクの売買物件21件のうち**300万以下は0件**。
市の登録台帳は不定期にしか更新されないので、人が見に行く運用は続かない。
出た瞬間に気づけるかどうかがすべて。

## データ源

小松市HPの[空き家バンク(リスト)](https://www.city.komatsu.lg.jp/soshiki/1027/akiya_akishitsubanku_komatsuchoukajouhoubanku/16922.html)
にある **空き家バンク登録台帳PDF**（1枚もの・全物件が表になっている）を読む。

公的サイトのみ。ポータル（SUUMO/athome/健美家）はスクレイピング禁止のため触っていない。
なお `komatsu-c17203.akiya-athome.jp` の空き家バンク検索サイトは**現在0件**で、
実データは市HPのPDF側にしかない。

## 使い方

```bash
cd fudosan_app
pip3 install -r requirements.txt

python3 run.py --report   # 今ある売買物件を全部判定して一覧（通知しない）
python3 run.py            # 新着・値下げだけ通知（launchdが叩くのはこれ）
python3 run.py --test     # LINEへテスト送信
```

Finderからは `物件チェック.command` をダブルクリック。

### LINE通知の設定

既存の公式LINE Botのチャネルをそのまま使う。Renderのline_botの環境変数から2つコピー：

```bash
cp .env.example .env
# LINE_CHANNEL_ACCESS_TOKEN と LINE_ADMIN_USER_ID を貼る
python3 run.py --test
```

未設定でもMacの通知センターと標準出力には出る（取りこぼさない）。

### 自動巡回（1日3回）

```bash
cp com.taitanpro.fudosan-watch.plist ~/Library/LaunchAgents/
launchctl load ~/Library/LaunchAgents/com.taitanpro.fudosan-watch.plist
```

ログは `data/watch.log`。外すときは `launchctl unload`。

## 通知の中身

```
🏠 新着 No.999　今江町（今江校下）
180万 / 92㎡ / 1976年築 / 木造2F / 駐車2台

🙅 この家賃想定では利回り20%に届かない
想定家賃 5.7万（校下「今江」の賃貸実績）
年間手残り 44万 → 総投資上限 219万
売出のまま買うと総投資 295万（実質14.8%）
　内訳: 物件180万＋諸費用65万＋修繕50万
👉 指値上限 104万　これ以下で買えば20%

⚠️ 現状有姿売買（契約不適合の免責特約を要確認）
```

**指値上限**が本体。「いくらまでなら式に収まるか」を逆算して出すので、
そのまま業者に出す数字になる（ガイド §3「感情の値切りではなく計算書の提示」）。

## 判定のロジック

| 判定 | 意味 |
|---|---|
| BUY | 売出価格のままで式に収まる |
| NEGO | 指値すれば収まる（売出の6割以上で届く） |
| PASS | この家賃想定では届かない |
| INFO | 価格が「要相談」で判定不能 |

**通知するもの**
- 300万以下の戸建て → 判定がPASSでも必ず通知（ガイドの狩場。家賃UP・DIY修繕の余地が残る）
- 300万超 → BUY / NEGO / INFO のみ
- 既知物件の値下げ

### 想定家賃はどう出しているか

同じ台帳に載っている**小松市内の賃貸物件の㎡単価**（中央値）から出す。相場の推測ではなく実データ。
- 校下ごとにサンプルが2件以上あればその校下の単価を使う
- 事業用・一棟貸しの外れ値（㎡単価250〜900円の外）は除外
- 駐車場0台は▲15%、1台は▲5%（ガイド §6「小松は車社会」）
- 上限7万（ガイド §8「法人契約・家具付きで月6〜7万も視野」）で頭打ち

2026年7月の実測で全体中央値 **483円/㎡**。ガイドのモデルケース（85㎡で4.5万＝529円/㎡）とほぼ一致。

### 前提値を変える

`config.py` に諸費用・年間経費・修繕デフォルトを全部出してある。

見学して実額が分かったら `data/overrides.json` で物件ごとに上書きする：

```json
{"390": {"renovation": 1200000, "rent": 50000, "note": "屋根の葺き替えが要る"}}
```

## その他欄からの危険信号

台帳の備考を見て自動でフラグを立てる（ガイド §2 の質問リストに直結）：
市街化調整区域 / 接道・再建築 / 現状有姿 / 未登記 / 農地・畑付き / 借地権。

**このアプリは机上の一次スクリーニングまで**。撤退3条件（傾き・シロアリ・屋根）は
現地で見ないと分からないので、通知が来たら §6 の見学チェックリストへ。

## 対象外

- 空き室バンク・空き地バンク（賃貸戸建て投資の対象外）
- 業者の自社サイト（佐々木不動産・ミヨシ開発等）
  → 未公開物件はネットに出ないので、ガイド §9 の通り電話が正解
