## IRIAM（イリアム）とは？2026年の運営体制と特徴

IRIAMは、**「1枚のイラスト」を読み込むだけで、自動でリアルタイムに動くキャラクター（Live2D風アバター）として配信できる**、Vライバー特化型のライブ配信アプリです。

2018年にローンチされ、現在は**株式会社DUO（旧IRIAM社、2023年にDeNAグループ入り）が運営**しています。**Pocochaを運営するDeNAと同じグループ**である点は、業界内でも重要なポイントです。

### IRIAMの基本スペック

| 項目 | 内容 |
|---|---|
| **運営会社** | 株式会社DUO（DeNAグループ） |
| **配信スタイル** | キャラクター（Vライバー）特化型 |
| **必要なもの** | スマホ・キャラクターイラスト1枚・マイク（スマホ内蔵可） |
| **顔出し** | **完全不要**（カメラは声と口の動きの取得のみ） |
| **対応OS** | iOS / Android |
| **収益化** | 初日から可能（収益化条件なし） |
| **年齢制限** | 配信者は **18歳以上**（高校生不可） |

> **重要**：IRIAMは「Vtuberアプリ」ではなく、正式には**「キャラクターライブ配信アプリ」**と位置付けられています。VtuberというよりVライバー、つまり**「キャラクターの皮を被ったライブ配信者」**としてのコミュニティが軸です。

### Vtuberとの違い｜「収録動画」ではなく「リアルタイム配信」

世間一般の「Vtuber」は、**YouTubeに収録動画をアップする活動**を指すことが多く、**編集・サムネ作成・台本作成**など膨大な制作工数がかかります。一方IRIAMは、**完全リアルタイムのライブ配信専用**プラットフォーム。

- **編集・サムネ作成 → 不要**
- **凝った台本 → 不要**（雑談ベース）
- **長時間の制作作業 → 不要**（配信時間＝活動時間）

**「動画制作は無理だが、毎日2時間しゃべるなら出来る」**——そんな人が一番フィットします。

### ライブ配信市場でのIRIAMのポジション

| プラットフォーム | スタイル | 月間配信者数（推定） |
|---|---|---|
| Pococha | 顔出しライブ配信 | 大規模 |
| 17LIVE | 顔出しライブ配信 | 大規模 |
| **IRIAM** | **キャラ配信特化** | **国内Vライバー市場で最大級** |
| ふわっち | 顔出し雑談 | 中規模 |

IRIAMは**国内のVライバー（キャラ配信）市場では事実上の最大手**です。ライバーの母数が多いということは、**競争は激しいが、コミュニティ・イベント・公式の盛り上がりも大きい**ということ。新規参入のメリットは依然として大きい段階です。

## なぜ顔出し不要で配信できるのか｜IRIAMの技術的な仕組み

IRIAM最大の特徴は、**従来のVTuberに必須だった「Live2Dモデリング作業」が一切不要**な点です。一般的なVTuberはモデル制作だけで**5〜30万円**かかりますが、IRIAMでは**イラスト1枚をアップロードするだけで完了**します。

### IRIAM独自の「キャラ自動生成エンジン」

| 工程 | 一般的なVTuber | IRIAM |
|---|---|---|
| イラスト準備 | 必要 | 必要（**1枚のみ**） |
| Live2Dモデリング | 必要（5〜30万円・1ヶ月） | **自動生成（無料・数分）** |
| 専用機材 | PC・トラッキングカメラ | **スマホのみ** |
| トラッキング | 顔表情・体の動き | **声・口の動きのみ** |
| 配信開始までの日数 | 1〜2ヶ月 | **最短2日** |

### 顔は本当に映らないのか？

**結論：映りません。** IRIAMが取得しているのは「**声**」と、声に連動した「**口の動き**」のみ。スマホのインカメラは使いますが、**映像はサーバーに送信されず、リアルタイムでアバターの口パクに変換されるだけ**です。

> **現役マネージャーの本音**：「顔出しが嫌で配信を諦めていた」という相談者の8割以上が、IRIAMを試した瞬間に**「これなら出来る」**と前のめりになります。心理的なブロックを外す効果は、想像以上に大きいです。

### IRIAMが向いている人・向いていない人

| 向いている人 | 向いていない人 |
|---|---|
| 顔出しに抵抗がある | 自分の顔を活かしたい |
| 声に少し自信がある／磨きたい | 話すよりダンスやパフォーマンスで魅せたい |
| 世界観・キャラ作りが好き | 素のキャラのまま勝負したい |
| 副業バレを最大限避けたい | 顔バレを気にしない |
| イラストや二次元文化に親和性がある | リアル系インフルエンサーを目指す |
| コアなファンと深く繋がりたい | とにかく広く浅くフォロワーを稼ぎたい |

> **重要**：「絵が描けないからVtuberは無理」と諦めていた人にこそ、IRIAMは突破口になります。**プロのイラストレーターに5,000円から発注できる時代**なので、**「絵の才能」と「Vライバー適性」は完全に分離**して考えてOKです。

## IRIAMを始める前に必要な3つの準備

### 1. キャラクターイラスト（最も重要）

IRIAMで使えるイラストには**明確な仕様**があります。**この仕様を守らないとアバター化されません**。

| 項目 | 推奨仕様 |
|---|---|
| サイズ | **1024×1024px以上**（正方形推奨） |
| ファイル形式 | PNG（背景透過） |
| キャラの構図 | **正面顔・上半身**（バストアップ） |
| 顔の角度 | **正面（傾き5度以内）** |
| 表情 | **口を閉じた状態**（自動で口パクが付く） |
| 髪・小物 | 顔にかからないこと |

#### イラストの入手方法

| 方法 | 費用 | 特徴 |
|---|---|---|
| **ココナラで依頼** | 5,000〜30,000円 | プロのイラストレーターに発注。商用利用OKを必ず確認 |
| **SKIMA で依頼** | 3,000〜20,000円 | Vライバー向けイラストが豊富 |
| **AI生成（NovelAI等）** | 月額1,500円〜 | 安価。**著作権・商用利用条件を必ず確認** |
| **自分で描く** | 0円 | 絵が描ける人向け |

> **重要**：他人のイラストを無断使用すると、**アカウント永久BAN＋著作権侵害で訴訟リスク**があります。**必ず「商用利用OK」と書面で確認**してから使用してください。

### 2. 配信機材

IRIAMは**スマホ1台で完結**するのが最大の利点です。最低限必要なものは以下のとおり。

| 必須度 | アイテム | 推奨スペック・価格 |
|---|---|---|
| **必須** | スマホ | iPhone 11以降 / Android 8.0以降 |
| **必須** | Wi-Fi環境 | 上り 5Mbps 以上 |
| **推奨** | 外付けマイク | 3,000〜10,000円（声質UPで投げ銭が増える） |
| **推奨** | リングライト | 2,000〜5,000円（顔は映らないが暗いと音質に影響） |
| **推奨** | スマホスタンド | 1,000円〜（手ブレ防止） |
| あると便利 | ポップガード | 500円〜（吐息ノイズ軽減） |

> **マイクの選び方**：IRIAMは**声がすべて**です。スマホ内蔵マイクでも配信は可能ですが、**外付けの単一指向性マイク（SHURE MV5・FIFINE等）に変えるだけで投げ銭が体感1.5〜2倍**になるケースが珍しくありません。

### 3. 声と話し方の準備

IRIAMはキャラクターの皮を被るため、**「キャラ設定（声色・口調・性格）」を最初に固める**ことが、長く伸びるための最重要ポイントです。

- **声色**：地声 or 作り声（無理のない範囲で）
- **一人称**：私／僕／俺／あたし／キャラ独自の呼び方
- **口調**：丁寧・タメ口・お嬢様・執事・関西弁など
- **性格設定**：3行で書けるレベルまで言語化

> **現役マネージャーの本音**：声優志望や配信慣れしている人ほど「**作り声**」で攻めがちですが、**1日2〜3時間配信を毎日続けると喉が壊れます**。**地声に少し寄せたキャラ**の方が長期的に伸びます。

実際にTAITAN PROで新規ライバーに記入してもらっている**キャラ設定シートのテンプレ**です。配信開始前に、最低限ここまで言語化しておくと、**初配信から軸がブレない**話し方ができます。

## IRIAMの始め方｜5ステップ完全ガイド（最短2日で配信開始）

### STEP 1. アプリのダウンロードとアカウント作成（10分）

App Store / Google Play から「IRIAM」を検索してインストール。**Apple ID / Google アカウント / メールアドレス / 電話番号**のいずれかで登録できます。

- **配信者登録**には**18歳以上の本人確認書類**が必須
- 高校生は**配信不可**（視聴のみ可能）
- 親権者同意があっても**18歳未満は配信不可**

### STEP 2. キャラクターイラストの準備とアップロード（1〜7日）

前述の仕様に沿ったイラストを用意し、アプリ内の「キャラクター登録」画面からアップロード。

- アップロード後、**自動でアバター化（数分〜10分程度）**
- 表情・口の動きを試す画面で**自動生成の仕上がりをチェック**
- うまく動かない場合は**イラストを差し替えて再アップロード**

### STEP 3. プロフィールとキャラ設定の入力（30分）

- **キャラ名**：覚えやすく検索されやすい名前
- **自己紹介文**：200〜300字程度（配信時間帯・趣味・キャラ設定）
- **配信ジャンル**：雑談／歌／ASMR／ゲーム／お悩み相談 等
- **アイコン・ヘッダー画像**：イラストレーターに合わせて発注しておくと統一感が出る

### STEP 4. 初配信の準備（前日まで）

- **配信タイトルテンプレート**を3〜5個用意
- **トーク台本**（5〜10分の自己紹介・キャラ紹介・趣味話）
- **コメント返しのパターン**（はじめまして／久しぶり／ファンレベルアップ時 等）
- **配信時間帯の決定**（後述：21時〜24時が王道）

### STEP 5. 初配信開始（当日）

- **配信時間は最低60分**（短すぎるとレコメンドに乗らない）
- **コメント0でも喋り続ける**（1ヶ月は「壁打ち」覚悟）
- **配信終了後、必ず分析**（視聴者数・コメント数・新規/リピート比率）

> **現役マネージャーの本音**：初配信から1週間は、**コメントが付かないのが当たり前**です。ここで挫折する人が**全体の60%**。**最初の30日間を毎日2時間配信できるか**で、その後の成長カーブが決まります。

## IRIAMの収益化｜ファンレベルとエール（投げ銭）の仕組み

IRIAMの収益は、主に**3つの収入源**で構成されます。

| 収入源 | 内容 | 換金 |
|---|---|---|
| **エール** | リスナーから贈られるギフト（投げ銭） | **可能** |
| **ファンレベル報酬** | リスナーのファンレベルが上がるとライバーに報酬 | **可能** |
| **イベント報酬** | 公式ランキングイベントでの順位報酬 | **可能** |

### エール（投げ銭）の仕組み

IRIAMでは、リスナーが課金で購入した**「エール」**をライバーに贈ります。エールには**通常エール**と**カラーエール**があり、種類によってライバーへの還元単価が異なります。

> **重要**：エールの還元率（ライバー側の取り分）は**運営の規約により非公開部分が多く、また定期的に改定**されます。**ここでは具体的な%は明示せず**、「エール額面の一定割合がライバーの収益になる」と理解してください。詳細は**公式ヘルプセンターまたは事務所**で必ず最新情報を確認してください。

### ファンレベルの仕組み

リスナーは配信を見たりエールを贈ることで、**ライバーごとのファンレベル**を上げていきます。

- **ファンレベルが上がるほど**、ライバー側にも**報酬が加算**される設計
- リスナー側にも**バッジ・特典**が付与され、コミュニティ形成が進む
- **コアファンの育成こそがIRIAMで稼ぐ最大の鍵**

### イベント報酬

IRIAMでは**月次・週次の公式イベント**が頻繁に開催されます。順位入賞で**追加報酬・公式バナー掲載・コラボ権**などが付与され、新規ファンの獲得チャンスにもなります。

### 換金スケジュールと最低換金額

IRIAMの換金は、**月次集計→翌月以降に振込**という、Pocochaに近い後払い型のサイクルです。

| 工程 | 内容 |
|---|---|
| ① 配信でエール・報酬を獲得 | 当月1日〜末日 |
| ② 月次集計で報酬確定 | 翌月初旬 |
| ③ アプリ内から換金申請 | 翌月以降（**最低換金額あり**） |
| ④ 銀行口座へ振込 | **申請から数週間程度** |

> **重要**：**最低換金額・振込手数料・申請締切日**は運営により改定される可能性があります。**実際の数値は、必ずIRIAM公式ヘルプセンターで最新版を確認**してください。一般的に、**数千円単位の最低換金額**と、**数百円程度の振込手数料**が設定されています。

### 税金の扱い（重要）

IRIAMの収益も**Pocochaと同様に課税対象**です。

- **会社員の副業** → 年間 **20万円超で確定申告必須**
- **専業ライバー** → 年間 **48万円超で確定申告必須**
- **学生（扶養内）** → 年間 **48万円以下に抑える必要**

**「換金していないから大丈夫」は通用しません**。確定した報酬は、その年の所得として計上されます。**運営側から税務署へ支払調書が提出されるため、無申告は確実にバレます**。

## IRIAMでのリアルな月収目安｜駆け出し・中堅・トップの3層

**※下記はTAITAN PROで把握している複数事務所のIRIAMライバー実績の平均レンジです。配信時間・キャラの方向性・運営イベントの状況により大きく変動します。**

| 階層 | 月の配信時間 | 月収レンジ | 特徴 |
|---|---|---|---|
| **駆け出し（1〜3ヶ月目）** | 30〜60時間 | **0〜1万円** | コアファン0〜数人。レコメンド露出ほぼなし |
| **初級（3〜6ヶ月目）** | 60〜100時間 | **1〜5万円** | コアファン5〜10人形成。イベント参加開始 |
| **中堅（半年〜1年）** | 100〜150時間 | **5〜20万円** | コアファン20〜50人。イベント入賞経験あり |
| **上位（1〜2年）** | 150時間〜 | **20〜50万円** | コアファン100人超。月次イベント常連 |
| **トップ層** | 150時間〜 | **50万円〜数百万円** | 公式推し・大型イベント常勝・グッズ展開 |

> **現役マネージャーの本音**：IRIAMはPocochaほど**「配信時間そのもの」が直接報酬になる仕組みではありません**。代わりに**「コアファン1人あたりの単価」が高く**、少人数のリスナーでも**安定した月20〜30万円**を作れる人がいます。**広く浅くより、狭く深く**が向いている人にハマるアプリです。

## IRIAMで伸ばす5つのコツ｜マネージャー視点の実践テクニック

### 1. **配信時間帯は「21時〜24時」を死守する**

IRIAMの**ゴールデンタイムは21時〜24時**。リスナーの可処分時間が最大化するこの3時間を、**週5日以上**確保できると伸びが段違いです。

- 朝活（6〜8時）も穴場だが、初心者は夜帯から
- 深夜（25時以降）は固定ファンが付くまでは非効率

### 2. **コアファン3人を作るまで「全力ロックオン配信」**

IRIAMは**コアファン経済**です。最初の30日は、**毎配信に来てくれる3〜5人**を徹底的に大切にする。

- コメントは**全員に名前付きで返す**
- ファンレベルアップ時は**必ず祝う**
- **配信外でも公式コミュニティで反応**

### 3. **キャラ設定は配信開始から「絶対にブレさせない」**

途中でキャラ変更すると**既存ファンが一気に離脱**します。最初に決めた**声・口調・性格**は、最低半年は固定する覚悟で。

### 4. **コラボ配信で新規ファンを取り込む**

IRIAMには**公式コラボ機能**があり、他のライバーと相互送客できます。**自分より少し格上のライバー**にコラボ申請するのが鉄則。

### 5. **イベント参加は「狙いを絞って全力」**

毎週何らかのイベントが開催されますが、**全部に出ると消耗します**。月1〜2個に絞り、**入賞圏内を本気で狙う**方が効果的です。

### 伸びる人と伸びない人の差｜配信外の動きで決まる

配信そのものよりも、**配信外の積み重ね**で差が付くのがIRIAMの特徴です。

| 項目 | 伸びる人 | 伸びない人 |
|---|---|---|
| 配信前 | タイトル・トピック準備、コアファンへ予告 | ノープランで開始 |
| 配信中 | 全員に名前付きで返答、ファンレベル祝う | 一方的に喋るだけ |
| 配信終了直後 | 来てくれたリスナーへ個別お礼コメント | アプリを閉じて終了 |
| 配信オフ日 | SNS（X/Instagram）でキャラの呟き発信 | 何もしない |
| 月1回 | 配信データを振り返り、改善点を3つ抽出 | 感覚で続ける |

> **現役マネージャーの本音**：トップ層のIRIAMライバーは、**配信時間と同じくらい「配信外の時間」を投下**しています。**X（旧Twitter）でキャラの世界観を発信**し、**配信告知→当日配信→アーカイブ呟き→翌日のお礼**まで一連のサイクルを回している人が、結局は伸びます。

## IRIAMでありがちな失敗5選

### 失敗1. **イラストの著作権トラブル**
AI生成イラストや拾い物を使用 → **アカウント凍結**。**必ず商用利用OKの素材**を使う。

### 失敗2. **キャラ設定をブラしすぎて固定ファン離脱**
「今日は元気に」「今日は落ち着いて」と日替わり → **誰のファンか分からなくなる**。**ブレない世界観**が命。

### 失敗3. **配信時間が短すぎてレコメンドに乗らない**
30分以下の配信を繰り返す → **アルゴリズム上の評価が上がらない**。**最低60分・週5日**は確保。

### 失敗4. **声を作りすぎて喉を壊す**
無理な高音キャラ → **3ヶ月で声が出なくなり休止**。**地声＋αで持続可能なキャラ**を選ぶ。

### 失敗5. **エール単価ばかり気にして配信が無機質になる**
「投げてくれたらお礼」「投げないと反応薄い」が透ける配信 → **コアファンが冷める**。**まず人として愛される**ことが先。

### 失敗6. **イベント爆死で精神的に折れる**
「初めてのイベントで全力 → 上位入賞ならず → 燃え尽き」**初イベントは練習と割り切る**。本番は3〜4回目以降。

### 失敗7. **他ライバーと比較して病む**
SNSで「同期が月50万稼いだ」を見て自分を責める → **配信のクオリティが落ちる悪循環**。**他人と比べず、昨日の自分と比べる**。

## 事務所所属 vs フリー｜IRIAMで本気で稼ぎたいならどっち？

IRIAMは**フリー（無所属）でも収益化は可能**ですが、**月10万円以上を本気で目指す**なら事務所所属を強く推奨します。

### 事務所所属のメリット

| メリット | 内容 |
|---|---|
| **イベント戦略のサポート** | どのイベントを狙うか・どう走るかをマネージャーが一緒に設計 |
| **配信改善のアドバイス** | プロ視点で「ここを直せば伸びる」を毎週フィードバック |
| **コラボ斡旋** | 事務所内・他事務所のライバーとの相互送客 |
| **税務サポート** | 確定申告・経費計上・節税の相談 |
| **メンタルケア** | 数字に一喜一憂しがちなライバーの精神的支柱 |
| **公式イベント情報** | 一般公開前の情報を事前共有してもらえることも |

### 事務所所属のデメリット

- **報酬の一部が事務所手数料**として差し引かれる場合あり
- **専属契約**で他アプリとの兼業が制限されることがある
- **合わない事務所に入ると逆効果**（連絡頻度・サポート姿勢の相性が大事）

### 事務所選びの3つのチェックポイント

1. **IRIAM公式認定の有無**：認定事務所はイベント情報・公式サポートで優位
2. **ノルマ・違約金・初期費用**：**「すべて0円」が今の業界標準**。徴収する事務所は要警戒
3. **マネージャーの返信スピード**：**24時間以内**に返信が来るかは超重要

> **現役マネージャーの本音**：「事務所に入ると搾取される」は**5〜10年前の古い印象**。今は**所属することで純利益が増える設計**の事務所が主流です。**最低でも3社の無料相談を受けてから決める**のが鉄則。

## よくある質問（FAQ）

### Q1. 完全に絵が描けないのですが、始められますか？
A. **問題ありません**。ココナラやSKIMAで5,000〜30,000円でプロのイラストレーターに発注できます。**「IRIAM用」と伝えれば仕様に沿って描いてくれる**ことがほとんどです。

### Q2. 動くLive2Dモデルは別途用意しなくて良いのですか？
A. **不要です**。これがIRIAMの最大の強み。**1枚のイラストをアップロードすれば自動でアバター化**されます。

### Q3. 配信中、本当に顔は映らないのですか？
A. 映りません。**インカメラは「声と口の動きの取得」のみ**に使われ、映像データは送信されません。**部屋の様子・素顔・服装は一切配信に映りません**。

### Q4. 声バレが怖いです。声を変える方法はありますか？
A. **多少は変えられますが、限界あり**。地声から少しトーンを変える程度が現実的。**ボイスチェンジャーアプリ併用も可能**ですが、リアルタイムの会話には不向きです。**地声に近いキャラ作り**が一番安全です。

### Q5. 18歳未満ですが配信できますか？
A. **できません**。IRIAMの配信者は**18歳以上（高校生不可）**が必須。視聴は年齢制限内で可能です。

### Q6. 副業ですが、会社にバレますか？
A. **顔バレリスクは限りなく0**ですが、**収益が年20万円を超えると確定申告が必要**で、住民税経由でバレるリスクはあります。**確定申告書の住民税欄で「自分で納付」を選択**すれば、ほぼ防げます（詳細は[Pococha換金ガイド記事](#)も参照）。

### Q7. 事務所所属とフリー、どちらが良いですか？
A. **目的によります**。

- **趣味で月数万円稼げればOK** → **フリー**で十分
- **副業で安定して月10〜30万円稼ぎたい** → **事務所所属**を強く推奨
- **専業で本気で伸ばしたい** → **事務所所属一択**

事務所所属のメリットは、**イベント戦略・配信改善アドバイス・コラボ斡旋・税務サポート**など多岐にわたります。**IRIAM公式が認定する事務所**もあるため、所属時は必ず公式認定の有無を確認してください。

### Q8. PocochaとIRIAMを兼業できますか？
A. **規約上は可能**ですが、**事務所所属の場合は専属契約があるかを必ず確認**。**両方を本気でやると配信時間が分散して両方とも伸びない**ため、**まずどちらか1本に絞る**のが現実的です。
