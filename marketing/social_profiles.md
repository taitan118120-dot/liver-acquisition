### ⚠️ 固定ポストは「プロフィール」とは別に走査すること（2026-08-08 の死角）

X @taitan_LIVER の固定ポスト（tweet id `2037849449498837271`・2026-03-28 の初投稿）に、
**4ヶ月以上ずっと確定ファクト違反4点が公開されたまま**だった。

```
私は現役プレイヤーであり、累計150名を集客・育成し、傘下11代理店を統括するオーナーです。
…本気で結果を出したい方のみDMでご相談を。
```
① `累計150名` → 確定は200名／② `傘下11代理店を統括` → 確定表記は「11の配信代理店と提携」／
③ CTAがDM → 導線は特典PDF→LINE登録／④ `現役プレイヤー` → 確定は「**元**Pococha S帯」（**同じアカウントのbioと自己矛盾していた**）

**取り残された理由は走査対象の設計**。記事本文の一括ファクト更新はプロフィール文を対象外にしており
（2026-07-31 に是正）、**その是正のときも固定ポストは対象外**だった。
`link_guard.py` はリンクの生死しか見ず文面の中身を見ない。
→ **「一度書いたら二度と読み返さない場所」を毎日読み直す番犬** `social_profile_guard.py` を新設した。

**固定/固定解除の公開APIは X にも Threads にも存在しない**。投稿と削除はAPIでできるが、
**固定操作だけはアプリ側で手動**。差し替えは `social_pinned_publish.py`（ワークフロー
`social_pinned_publish.yml`）で行う。

**Threads Web UI の落とし穴**：「自己紹介を編集」「名前を編集」のサブ画面にある「完了」は**サブ画面を閉じるだけで保存されない**。編集後に外側ダイアログを最下部までスクロールし、**白い「完了」ボタンを押して初めて保存**される。リンク欄だけは例外でサブ画面の「完了」で即保存される（そのため片方だけ反映されて気づきにくい）。変更後は必ずプロフィールを再読み込みして実画面で確認すること。

## 運用の鉄則（全媒体共通）
- 投稿で売り込まない。リンク・CTAは出さない。変換はこのプロフが担う
- Threads：投稿＋「副業/ライバー気になる」層へのリプで母数を取る（手動）
- X：リプ営業はBANリスクのため**しない**。ポスト単体で引用RT・いいねを狙う
- Instagram：投稿は週3回まで。DM誘導はしない（プロフのリンクのみ）
- 事務所の話は"怒り・信念"の文脈でだけ（宣伝に見せない）
- **プロフィールを変えたらこのファイルも必ず同時更新する**（今回の乖離の原因は正本だけ更新して実プロフを放置したこと）
- **「プロフィール」には固定ポストとハイライトを必ず含めて数える**。bioだけ直して固定ポストを放置したのが2026-08-08の事故
- 毎日 `social_profile_guard.yml` が実物とこのファイルを突合する。**このファイルを直したら実物も直す**（逆も同じ）。片方だけだと翌朝Issueが立つ
