# 交流会スケジュール アプリ（kouryukai_app）

石川・金沢の交流会で **代理店パートナー** を獲得するためのスケジュール＆成果記録 PWA。
バックエンド不要・データはブラウザの localStorage に保存。

作成日：2026-06-21
元データ：`data/agency_networking_events.md`

## 機能
- 直近の交流会7件を seed 済み（こくちーずプロから抽出）
- タブ：今後 / 参加済 / すべて
- 各イベントをタップ → 状態（未定/申込済/参加済/見送り）・名刺交換数・興味あり人数・LINE交換数・メモを記録
- ＋ボタンでイベント追加、編集・削除も可
- ヘッダーに累計サマリー（名刺・興味あり・LINE交換）→ どの交流会が効くか分かる
- バックアップ：JSON書き出し / 読み込み（localStorageは端末依存なので定期的に書き出し推奨）

## iPhoneでアプリとして使う（推奨）
PWAのインストール（ホーム画面追加＋オフライン動作）には http 配信が必要。

```bash
cd ~/ライバー獲得/kouryukai_app
python3 -m http.server 5070
```
→ 同じWi-FiのiPhone Safariで `http://192.168.11.31:5070/` を開く（IPはMacのローカルIP。変わったら `ipconfig getifaddr en0` で確認）
→ 共有ボタン →「ホーム画面に追加」でアプリ化。

## Macでサッと開くだけ
`index.html` をブラウザで直接開くだけでも全機能動く（localStorage保存）。
※ file:// 直開きだと service worker（オフライン化）だけ無効。記録機能は問題なし。

## 注意
- データは「開いた端末・ブラウザ」に保存される。iPhoneとMacでは別データになる。
- 機種変更・キャッシュ削除で消えるので、こまめに「バックアップ書き出し」を。
