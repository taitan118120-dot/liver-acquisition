# LINE面談台本（応募が来た後の受け皿）

作成日：2026-06-09
用途：求人媒体・ジモティー・Wantedly・Note経由でLINEに応募が来た後、面談→入会まで持っていく台本。
原則：**即レス（応募から数時間以内）**／売り込まない／不安を取り除く／必ず面談に繋ぐ。

---

## ステップ0：応募直後の初動（最重要・即レス）
応募・友だち追加が来たら、できるだけ早く（理想は当日中）返す。放置＝離脱。

```
はじめまして、ライブ配信事務所TAITAN PROの〇〇です😊
ご連絡ありがとうございます！

無理な勧誘は一切しないのでご安心ください🙆‍♀️
まず簡単にいくつか教えていただけますか？

①配信の経験はありますか？（未経験/少しある/配信中）
②やってみたいプラットフォームの希望はありますか？（Pococha/TikTok LIVE/17LIVE/まだ分からない）
③1日にどれくらい配信できそうですか？（例：夜に1〜2時間、週末だけ など）

※どこで募集を見ていただきましたか？（差し支えなければ）
```
→ 返信が来たら `recruitment_tracker.csv` に channel を記録。

## ステップ1：ヒアリングと共感
返ってきた内容に**まず共感**してから、軽く安心材料を渡す。

```
ありがとうございます！未経験からスタートの方、うちは本当に多いです👍
（例：夜に1〜2時間でも、続け方さえ設計すれば十分伸ばせます）

うちの特徴を簡単にお伝えすると、
・還元率100%+α
・所属200名、元Pococha Sランクの代表が配信を直接アドバイス
・ノルマなし（配信頻度・時間は自由）

もっと具体的な進め方は、オンラインで15〜30分お話しするのが早いです。
来週あたりで、ご都合のいい日はありますか？😊
```

## ステップ2：面談の日程を取る（ここを必ず通す）
- 日時は**相手の都合を先に聞く**（こちらから候補を指定しない）。合わせるのはこちら側。
- ざっくりでいいと伝えると答えやすい（「土曜の夜」「平日の遅め」など）。
- 「服装自由・カメラオフでもOK・15分だけでも」と**ハードルを下げる**。

```
ありがとうございます！
〇〇さんのご都合のいい日時を教えてください😊
（例：「明日の21時」「土曜の夜」「平日の遅めの時間」など、ざっくりで大丈夫です）

カメラはオフでも大丈夫です。15分くらい、ざっくばらんにお話ししましょう☕️
```
→ 予約が取れたら tracker に「面談予約=○」。前日にリマインドを送る。

## ステップ3：面談の進め方（15〜30分）
1. **アイスブレイク**（緊張をほぐす・配信に興味を持ったきっかけを聞く）
2. **相手の目的を確認**（お小遣い稼ぎ？本業にしたい？人と話したい？）
3. **目的に合わせて始め方を提案**（プラットフォーム・配信時間・最初の目標）
4. **不安・疑問に答える**（下の「よくある不安」参照）
5. **次の一歩を明確に**（必要なもの・初配信日の仮決め）

→ 面談したら tracker に「面談実施=○」。

## ステップ4：クロージング〜入会手続き
売り込まず、「**次に何をすればいいか**」を具体的に示すだけ。

```
お話しできて良かったです😊
〇〇さんの場合は、まず△△から始めるのが合っていそうです。

始めるなら、
①アプリの登録（やり方は画像付きで送ります）
②TAITAN PROの所属手続き（LINEで完結・5分）
③初配信日を一緒に決める

この流れです。気持ちが固まったら、いつでも「始めたいです」とメッセージください🙆‍♀️
（もちろん持ち帰って考えてもOKです）
```
→ 入会したら tracker に「入会=○」＋入会日。

## よくある不安への返し（テンプレ）
- **「本当に稼げますか？」**
  → 「正直、配信時間や続け方で個人差が大きいです。だから"必ず月◯万"とは言いません。ただ、続けられるように設計を一緒に立てるので、未経験でも諦めずに伸ばせます」（誇大表現を避けつつ誠実に）
- **「顔出ししたくない」** → 「声だけ・顔出しなしの配信スタイルも相談できます」
- **「費用はかかりますか？」** → 「初期費用・月額0円、還元率100%+αです。契約条件は面談で全部お伝えします」
- **「忙しくて続けられるか不安」** → 「配信時間は完全に自由です。週末だけ・夜だけの方も多いです」
- **「ノルマありますか？」** → 「ノルマはありません。自分のペースでOKです」

## 追客（返信が途絶えたとき）
- 1〜2日空いたら**1回だけ**軽くフォロー。しつこくしない（=DMで嫌われた失敗を繰り返さない）。
```
〇〇さん、その後いかがですか？😊
もし今は迷い中でも全然大丈夫です。気が向いたタイミングでまた声かけてくださいね🙆‍♀️
```
- それでも反応なければ深追いしない。

## 代理店パートナー応募の場合（分岐）
- ヒアリングは「これまでのご経験（営業/人材/接客など）」「副業か本業志向か」「使える時間」。
- 面談では**事業の仕組み・継続報酬の考え方・サポート体制**を説明（収入は"成果により変動"と正直に）。
- tracker は target=代理店 で記録。

## 運用の鉄則
- **即レス**が命。応募の鮮度が落ちると一気に冷める。
- 売り込まない。「相手の目的を叶える手伝い」のスタンス。
- 各段階を必ず `recruitment_tracker.csv` に記録 → どこで落ちてるか可視化。
