# 求人媒体 掲載手順（ライバー / 代理店）

原稿：`data/liver_recruitment_jobpost.md`（ライバー）/ `data/agency_recruitment_jobpost.md`（代理店）
予算：月数万円 → まずIndeedスポンサー枠に集中
計測：`data/recruitment_tracker.csv`

---

## A. Indeed（本命・まずここ）

### 1. 事業者アカウント
- https://employers.indeed.com/ から「求人を掲載」→ Googleアカウント等で事業者登録
- 会社名：TAITAN PRO（※カーブアウト表記NG）

### 2. 求人を作成（ライバー用）
| 項目 | 入力 |
|---|---|
| 職種名 | 例：ライブ配信ライバー（未経験OK・在宅） |
| 勤務地 | 「リモート」「在宅」を選択（全国） |
| 雇用形態 | 業務委託 |
| 給与 | 「歩合制／出来高」。固定額は入れない（補足に「収入は配信内容・時間により変動」） |
| 仕事内容 | `liver_recruitment_jobpost.md` の本文をコピペ |
| 応募方法 | ①Indeed内応募＋質問設定 or ②外部リンク（公式LINE `https://lin.ee/xchCfdn`） |

### 3. 代理店用も別求人で作成
- 同様に `agency_recruitment_jobpost.md` を使い、職種名「ライバー代理店パートナー（業務委託・在宅）」で**別掲載**。
- 応募者層が違うので必ず分ける。

### 4. スポンサー（有料）設定
- 1求人を「スポンサー」にして**日予算 700〜1,000円**（月2万前後）。まずライバー求人を優先。
- 1〜2週間回して、応募単価（CPA）を見る。

### 5. 計測の仕込み（最重要）
- 応募が来たらLINE冒頭で「どの求人で見ましたか？」を必ず聞く。
- または求人ごとに**合言葉**を本文末に入れる（例：ライバー=「『配信』とメッセージ」/代理店=「『代理店』とメッセージ」）。
- `recruitment_tracker.csv` に target×channel で記録。

## C. 掲載後の判定（2週間後）
- 媒体別に 応募数 / 面談数 / 入会数 / CPA を集計（tracker.csv）
- 効いた媒体・求人に予算を寄せる。効かない方は文面（タイトルA/B/C）を差し替えてテスト
