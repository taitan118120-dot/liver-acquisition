| | PV増 | 比率 |

> **記事を量産しても、その月の伸びにはほとんど効かない。** 効いているのは過去記事のSEO成熟。
> 今いちばん費用対効果が高いのは「新しく書く」ではなく **「すでに読まれている記事の中身と導線を直す」**。

参考: 上位5本で全PVの20.7% / 上位10本で33.9% / **上位30本で63.0%**。

## 2. 代理店（＝事務所を"作る側"）だけを取り出す

対象14本。月間PV合計 400（全体の12.0%）、週間68（11.6%）。

**この14本は実務型と募集型で9倍近い差がついている。**

### 当たっている＝実務型（月間PV合計 253）

| 月間PV | PV/日 | 記事 |
|---|---|---|
| 106 | 1.53 | ライバー代理店のスカウト術｜DM返信率を上げる実践テクニック |
| 81 | 1.60 | ライバー事務所を開業する方法｜代理店との違いと独立ロードマップ |
| 37 | 0.40 | 「弊社ライバー事務所です」と書いた瞬間、返信率は半分になる｜スカウトDM運用論 |
| 15 | 0.60 | ライバーマネージャーとは？仕事内容・なり方・年収 |
| 14 | 0.70 | 事務所を開業して「最初の10人」が集まるまで |

### 沈んでいる＝募集型（月間PV合計 29）

| 月間PV | PV/日 | 記事 |
|---|---|---|
| 12 | 0.39 | ライバー代理店は本当に稼げる？収入のリアルと成功者の共通点 |
| 10 | 0.39 | 【実例】会社員をしながら…代理店を並行して150万円超え |
| 4 | 0.23 | ライバー事務所の代理店とは？｜メリットと仕組みを徹底解説 |
| 2 | **0.16** | ライバー事務所の代理店（パートナー）になる方法 |
| 1 | 0.25 | 「月5万円の在宅副業」で5個失敗した私が代理店に落ち着いた話 |

> **結論：代理店パートナーを集めたいなら「代理店になりませんか」を書いてはいけない。**
> 「代理店とは」「なる方法」「稼げる？」は**誰も検索していない**（月間2〜12PV）。
> 一方「スカウトの返信率を上げるには」「事務所をどう立ち上げるか」は月間106・81PVで、
> **全記事中でも上位に食い込む**。検索しているのは「もう始める気がある人」であって、
> 「代理店って何？」の人ではない。
>
> 取るべき立ち位置は **「代理店の実務でいちばん役に立つ場所になる」**。
> そこに来た人をCTAで捕まえるほうが、募集記事を増やすより桁が違う。

これは前回の「〇〇におすすめの事務所の選び方 量産型は全滅（0.29）／開業・代理店・マネージャーの"作る側"は当たる（0.44）」の、さらに一段深い解像度版。**"作る側"の中でもさらに実務型／募集型で割れている。**

## 3. いちばん大きい穴：流入の本体から代理店への道が無い

全期間PV上位30本（＝全PVの63%）の本文を実測した。

| 実測項目 | 結果 |
|---|---|
| 内部リンク合計 | 67本 |
| うち**代理店記事へ**のリンク | **4本**（記事数では2本だけ） |
| LPリンク（ライバー向け `/beginner/`・LPトップ） | **27本** |
| LPリンク（**代理店** `/agency/`） | **2本** |

月3,342PVの本体はすべてライバー志望の導線に流れていて、**代理店funnelにはほぼ1滴も届いていない**。
公式LINEは welcome で「ライバー希望／代理店希望」を聞き分ける作りになっている（`line_bot/`）が、
**記事側で代理店の意図を立てていないので、LINEに着いた時点でほぼ全員がライバー志望として振る舞う**。

### さらに、代理店記事のCTA自体が壊れていた

14本すべてが**ライバー向けの特典PDF**『ライバー新人期スタートダッシュガイド』を提示していた。
「会社員をしながら代理店をやる1週間の組み方」を最後まで読んだ人に、
「新人ライバーの最初の30日」PDFを差し出していたことになる。

LPリンクも：`/agency/` へ 5本 / ライバー向けLPへ 5本 / **LPリンクなし 4本**。

原因は `note_article_generator.py` の `CTA_BLOCK` が**カテゴリに関係なく単一**だったこと。
代理店向けの特典PDF（`lead_magnet/agency_starter_guide.html`）は
2026-08-11 から公式LINE側に存在していたのに、記事側が一度も指していなかった。

→ **対応済み**（§5）。

## 4. もうひとつの穴：上位記事が回遊の行き止まりになっている

公開140本の本文を全件走査した結果、**「あわせて読みたい」ブロックが無い記事が40本、合計2,541PV（全PVの29%）**。

内訳：
- **17本は `data/note_boost_log.json` 上「実施済み(ok)」なのに消えている＝回帰**。
  8/8以降にPUTを打つ一括修正スクリプト（オンライン面談削除・かぜんせん修正など）が
  本文を書き戻した際に落ちたと見られる。
- 23本は 8/8 のboost以降に `note_auto_poster.py` が公開した新記事。
  **auto_poster は内部リンクを入れないので、新記事は必ずリンク0で世に出る。**

特に痛いのが：

| PV | 月間 | 記事 |
|---|---|---|
| 468 | 271 | 【全体1位】TikTokLIVE 収益化完全ガイド ← **内部リンク0** |
| 303 | 45 | 【全体4位】Pococha新人期間 完全攻略 ← **内部リンク0** |
| 284 | 104 | TikTok LIVE フォロワー1000人を集める方法 ← **内部リンク0** |
| 209 | 106 | **ライバー代理店のスカウト術**（代理店1位） ← **内部リンク0** |

流入1位の記事と、代理店1位の記事が、どちらもどこにも繋がっていない。

## 5. 実施したこと（2026-08-28）

1. **`note_article_generator.py` のCTAをカテゴリ別に出し分け**（`cta_block_for()`）。
   `agency` カテゴリは `/agency/` LP ＋『ライバー代理店パートナー スタートガイド』＋
   「登録後に『代理店』と送ってください」の一文へ。以後の新記事はこの間違いを繰り返さない。
2. **公開済みの代理店記事14本のCTAを貼り替え**（`note_agency_cta_publish.py`）。
   特典PDF名・LPリンク・LPリンクが無い記事への追加を1回のPUTでまとめて実施。
3. **`SEO_KEYWORDS["agency"]` を実測で入れ替え**。募集型（「代理店とは」「なる方法」
   「メリット・デメリット」）と、読者がライバー志望である事務所選び系（「面談の流れ」
   「口コミ・評判」「フリーvs事務所」）を退役。実務型（スカウト返信率／開業準備手順／
   ライバー育成／SNS集客／運営トラブル／会社員との両立）を p3〜2 で追加。
4. **`CATEGORY_WEIGHTS["agency"]` を 2 → 3**。代理店主軸（`project-agency-shift`）に配分を寄せる。
5. **`note_pv_report.py` の多ラベル集計バグを修正**。取得直後の `analyze()` に
   `clusters` が `"A|B"` の文字列のまま渡っていて、テーマクラスタ別の表が
   **1文字ずつのグループ**（「顔」「出」「し」…）になっていた。`--analyze` 経由では
   正しく出ていたので気づきにくい。

## 6. 次にやるべきこと（効果順）

1. **「あわせて読みたい」が消えた／入っていない40本を復旧する**（合計2,541PV）。
   `note_boost_publish.py` は `note_boost_log.json` に `ok` があるとskipするので、
   回帰した17本はログのエントリを消してから回す。**上位4本（1,264PV）だけでも先に。**
   その際、事務所・収入・キャリア系の記事の関連3本には**代理店記事を1本混ぜる**と
   §3の穴が同時に埋まる（`pick_related` はクラスタ重なりとタイトル類似で選ぶので、
   放っておくと代理店記事は絶対に選ばれない）。
2. **回帰を検知する番犬を足す**。「公開記事のうち あわせて読みたい／冒頭CTA が無いもの」を
   毎日数えてIssue化する。既存の `note_cover_guard` / `note_stock_guard` と同じ枠組み。
   一括修正スクリプトを回すたびに静かに剥がれるので、人手では気づけない。
3. **`note_auto_poster.py` が公開した新記事に内部リンクが入らない**問題を塞ぐ。
   公開直後に boost を1本だけ流すのが素直。
4. **代理店の実務記事を書き足す**（§2）。ただし優先度は上の3つより下。
   §0のとおり新記事の寄与は5%しかない。狙うなら「スカウト術」の周辺
   （返信率／育成／立ち上げ／集客）を深掘りする。**募集型は書かない。**
5. **税金・制度カテゴリは打ち切り**。2回連続最下位、9本で月間PV合計50。
6. 代理店記事に**確定ファクト違反が残っている**（「オンライン面談」「リスナー」呼び捨て、
   「何百人」）。今回のCTA貼り替えでは新規に増やしていないが、既存分は未修正。
