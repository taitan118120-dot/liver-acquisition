# 所属ライバー紹介プログラム キット

作成日：2026-06-27
目的：所属200名の「友達の配信者・配信に興味ある知人」を入会につなげる。審査ゼロ・コスト変動・最高変換のPullレバー。
背景：冷たい他人へのコールドDM500件→入会0。一方で**信頼関係のある所属200名**には一度も仕組み化して紹介を頼んでいない＝最大の未活用鉱脈。

ファクトは [project_taitan_pro_note_facts] 厳守（還元率100%+α／所属200名／元Pococha Sランク代表／誇大NG／「手数料なし」単独表記NG＝還元率100%+αとだけ）。
受け皿は `data/line_interview_script.md`、計測は `data/recruitment_tracker.csv`。CTAは公式LINE `lin.ee/xchCfdn` に集約。

---

## 1. 報酬設計（★三田さんが最終確定）

紹介は「言うだけ」では動かない。明確な報酬＋簡単な導線が必須。下記は推奨案。数字は確定前のたたき台。

**推奨：二段階＋成果連動（紹介者が動く理由を作る）**

| タイミング | 紹介者（所属ライバー）へ | 紹介された人へ |
|---|---|---|
| ① 入会（所属手続き完了） | 3,000円 | （任意）入会お祝い 1,000円 |
| ② 紹介された人が初月に一定配信を達成（例：初月◯時間 or ◯日配信） | 7,000円 | — |

- 二段階にする理由：①だけだと「とりあえず登録させて即離脱」が増える。②で**続く人**を紹介するインセンティブにする。
- 「紹介された人へのお祝い」を入れると、紹介者が声をかけやすくなる（相手にメリットを提示できる）。
- 上限なし／何人でも。多く紹介した子は表彰・追加ボーナスも検討可。
- ★決めること：①②の金額、②の達成条件（時間/日数）、お祝いの有無。決まり次第この表を更新。

> ⚠️ 募集文・告知に金額を出す場合、配信報酬と混同させない（「紹介してくれたら3,000円」は社内向け案内なのでOK。対外的な誇大表現にはしない）。

## 3. 紹介された人に転送するメッセージ（所属の子→お友達）

所属ライバーがそのまま友達に転送できる文。**送信者中立**で書く（誰が送っても成立）。

```
配信、ちょっと興味あったりする？☺️
私が所属してる配信事務所「TAITAN PRO」がすごく良くて、紹介してます。

・還元率100%+α（事務所に取られない）
・元Pococha Sランクの代表が直接アドバイスくれる
・ノルマなし、いつでも辞められる
・未経験スタートの人がほとんど

今お友達紹介やってて、始めると入会お祝いももらえるみたい🎁

もし少しでも気になったら、下の公式LINEに
「〇〇の紹介」って送ってみて👇
https://lin.ee/xchCfdn

無理な勧誘は一切ないから安心して大丈夫だよ😊
```

★「〇〇」＝紹介者の名前。これが**合言葉＝計測キー**になる。

## 4. 計測（「500件送って記録なし」を繰り返さない）

- 応募者がLINEで「〇〇の紹介」と名乗る → `data/recruitment_tracker.csv` に
  - `channel = 紹介`
  - `媒体詳細_合言葉 = 紹介者名`
  - 以降 LINE接続→面談→入会 を各段で記録。
- 入会が確定したら、**紹介者へ①の報酬を支払い**、tracker メモに「紹介者:〇〇／①支払済」。
- ②の条件達成を月末に確認 → 達成なら②支払い。
- 月次で「紹介経由の 応募/面談/入会 数」と「報酬支払総額」を集計 → CPA（1入会あたり費用）を出す。コールドDM（実質無限大）と比較すれば効果は一目瞭然。

## 5. 運用ステップ（最短で回す順）

1. **§1の報酬額を確定**（三田さん）。
2. §2の告知文を所属LINE（一斉 or グループ）に投稿。反応した子に§3の転送文を渡す。
3. 紹介で応募が来たら **`line_interview_script.md` で即レス対応**（応募の鮮度が命）。
4. tracker に記録 → 入会したら報酬支払い。
5. 2週間後に「告知に何人反応したか／応募何件か」を確認。反応が薄ければ、**個別DM**（一斉でなく、よく配信してる上位の子から個別に「〇〇さんなら良い人紹介してくれそうで」と頼む）に切り替え。一斉投稿は流れるので、**コア所属者への個別依頼が本命**。

---

## 6. なぜこれが効くか（コールドDMとの違い）

| | コールドDM（失敗） | 紹介プログラム |
|---|---|---|
| 接点 | 冷たい他人・警戒される | 信頼してる友達からの紹介 |
| ターゲット精度 | 容姿で誤爆（配信意思ゼロ） | 「配信に興味ある人」を友達が選別 |
| 審査・媒体リスク | BAN/規約の壁 | なし（社内施策） |
| コスト | 工数大・成果0 | 成果連動（入会した分だけ） |
| 計測 | 記録なし | 合言葉で完全追跡 |
