## ① ビジェント（最優先）
URL: https://www.bgent.net/ ／ カテゴリ：**法人の業務委託・副業 → 代理店/継続報酬系**

**タイトル（中・約40字）**
```
【完全在宅・継続報酬】ライバー代理店パートナー募集／初期投資0円・在庫なし
```

**本文**
```
ライブ配信事務所「TAITAN PRO」が、代理店パートナーを募集します。

ライブ配信をしたい人をスカウトし、TAITAN PRO への所属・配信開始をサポートするお仕事です。担当したライバーが配信を続ける限り、継続的な報酬が積み上がっていく代理店ビジネスです。

【特徴】
・初期投資ゼロ・加盟金・月会費なし
・継続報酬型：担当ライバーの活動期間中ずっと報酬が発生
・在庫・仕入れ・発送は一切なし。スマホとPCがあれば在宅で完結
・スカウト方法・育成ノウハウ・管理ツールはすべて提供。未経験からでも始められます
・200名を抱える事務所のリアルな運用ノウハウを共有

【こんな方に】
営業・人材紹介・コンサル経験を活かしたい方／継続的に積み上がる収入を作りたい方／副業から独立を目指したい方。

【報酬】
継続報酬型（担当ライバーの活動に応じた成果報酬）。固定の保証額はありませんが、サポートするライバー数の積み上げに応じて伸びます。※収入は活動量・継続期間・担当人数により変動します。

【応募の流れ】
公式LINEに「代理店BG」とメッセージ → オンライン説明・面談 → 研修・ツール提供 → スタート。
「仕組みだけ聞いてみたい」でもOKです。

詳細LP：https://taitan-pro-lp.netlify.app/agency/
```

## 再掲（bump）運用
掲示板系（friendlink等）は時間で埋もれる → **3〜4日ごとに再掲**で上位維持。
無料板はサクラ的連投NGだが、内容更新を伴う再掲はOK。logの「掲載日」を見て古い順に bump。

## 2週間後の判定
媒体別に 応募数 / 面談数 / 入会数 を tracker で集計 → 効いた媒体に時間を寄せる。
反応ゼロの媒体は タイトルを別案（短/中/長）に差し替えて再テスト。
