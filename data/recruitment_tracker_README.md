# 応募計測シートの使い方（recruitment_tracker.csv）

目的：**「500件送って記録なし」を二度と繰り返さない。** チャネル別・target別に
流入→応募→面談→入会を数え、どこで漏れてるか・どのチャネルが効くかを可視化する。

## 記録ルール
- 応募が来たら**1行追加**。LINE冒頭で必ず「どの求人で見ましたか？」を聞いて `channel` と `媒体詳細_合言葉` を埋める。
- `target` は `ライバー` か `代理店`。
- `LINE接続/面談予約/面談実施/入会` は ○ か 空欄（×）。段階が進むたびに更新。

## 列の意味
| 列 | 内容 |
|---|---|
| 応募日 | 応募が来た日 |
| target | ライバー / 代理店 |
| channel | Indeed / 求人ボックス / Note / LP / 紹介 / その他 |
| 媒体詳細_合言葉 | タイトルA/B/C、合言葉、記事名など出所の特定 |
| LINE接続 | LINE追加までいったか |
| 面談予約 | 面談を予約したか |
| 面談実施 | 実際に面談したか |
| 入会 | 入会・契約したか |

## 月末に見る数字（Googleスプレッドシートで集計）
channel × target ごとに：
- 応募数 / 面談実施数 / 入会数
- **応募→面談率**、**面談→入会率**（どの段で漏れてるか）
- 有料チャネルは **CPA = 使った広告費 ÷ 入会数**

例（スプレッドシートの関数）：
- Indeedの応募数：`=COUNTIFS(C:C,"Indeed")`
- Indeedの入会数：`=COUNTIFS(C:C,"Indeed",I:I,"○")`
- ライバーの面談実施数：`=COUNTIFS(B:B,"ライバー",H:H,"○")`

## 判断
- 月末に「効いたチャネル」を1つ特定 → 翌月そこに予算/労力を寄せる。
- 漏れてる段が「応募→面談」なら受け皿（LINE初動）を、 「面談→入会」ならクロージング台本を直す。
